# Twisted Tangle Level Web Viewer

Mở `index.html` bằng Chrome hoặc Edge, bấm **Chọn thư mục level**, rồi chọn `Assets/Resources/levels/so`.

Viewer chỉ đọc các file Unity `.asset`; không ghi hay thay đổi bất kỳ level nào. Nó hỗ trợ stage, dây, chốt và thống kê đối tượng cơ bản. Vì `RopeData` trong save data không lưu màu, màu dây trong preview được gán tuần tự để dễ phân biệt.
